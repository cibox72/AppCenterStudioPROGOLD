Utility GRU - Scrematura Automatica

Copia istantaneamente i file originali ad alta risoluzione basandoti sul file di selezione del cliente

!

Requisito Hardware

Questa utility richiede l'utilizzo di Google Chrome o Microsoft Edge per accedere in sicurezza alle cartelle locali del computer.

01 Elenco Nomi da Copiare (.GRU / .TXT)
Carica il file generato dalla selezione oppure incolla i nomi dei file direttamente nel box (uno per riga).
Clicca per caricare il file .GRU o .TXT
0 nomi rilevati e pronti
02 Cartella Sorgente (Originali Alta Risoluzione)
Seleziona la cartella locale del PC contenente tutti gli scatti originali (il sistema effettuerà una scansione ricorsiva).
Sfoglia cartella sorgente...
03 Cartella Destinazione (Es. "DA STAMPARE")
Indica la cartella locale all'interno della quale desideri salvare gli scatti estratti.
Sfoglia cartella destinazione...
GO Avvia Processo
