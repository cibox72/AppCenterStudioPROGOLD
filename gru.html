⚙️ GRU nel Browser

Esegui la scrematura automatica degli scatti: copia istantaneamente i file originali ad alta risoluzione basandoti sul file di pulizia del cliente.

📢 REQUISITO HARDWARE BLOCCANTE: Questa utility richiede l'utilizzo esclusivo di Google Chrome o Microsoft Edge sul computer per poter accedere in sicurezza alle cartelle locali.
