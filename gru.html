📋 Come Funziona - Guida Rapida

1
Il cliente seleziona le foto online → Il cloud genera automaticamente un file .txt con l'elenco delle foto scelte
2
Scarica il file .txt dal tuo CRM (nella sezione Notifiche)
3
Qui nella GRU: seleziona il file .txt, la cartella ORIGINALI (dal tuo NAS/HD) e la cartella di DESTINAZIONE
4
Clicca "🚀 AVVIA COPIA INTELLIGENTE" → La GRU copierà automaticamente SOLO le foto selezionate dal cliente!
